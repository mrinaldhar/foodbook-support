# Foodbook support

Foodbook helps you track what is in your kitchen, use food before it expires, cook from what you have, and keep shared shopping lists.

## Contact

Email **webmaster.mrinal@gmail.com** and include:

- what you were doing,
- what happened,
- what you expected,
- your iPhone/iPad model and iOS version,
- a screenshot if useful.

We aim to reply within a couple of days.

## Joining a shared kitchen

An invite link opens Foodbook and shows the kitchen before you join. If the link opens this website instead, tap **Open Foodbook**, or paste the invite code from the link into **Household → Have an invite?**

## Using the beta

1. Install **TestFlight** from the App Store.
2. Accept the Foodbook Pantry invitation.
3. Install the latest build.
4. Take a screenshot in the app and choose **Send** to attach it to feedback, or use **Settings → Send feedback**.
